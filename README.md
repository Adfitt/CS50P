## About This Course

CS50P — Introduction to Programming with Python is a free Harvard University course taught by David J. Malan.

The course introduces programming through Python, focusing on problem-solving skills and the fundamentals of writing, testing and debugging code.

Designed for students with or without prior programming experience, it provides hands-on practice through exercises inspired by real-world programming problems.

**Official Course:** [CS50P — Harvard University](https://cs50.harvard.edu/python/)

---

## Topics Covered

The course covers the fundamentals of Python programming, including:

- Functions, variables and data types.
- Expressions, operators and mathematical operations.
- Conditional statements and loops.
- Exception handling and error management.
- Python libraries and modules.
- Unit testing and debugging.
- File handling and data processing.
- Regular expressions and pattern matching.
- Object-oriented programming, classes and methods.
- Additional Python concepts and programming techniques.
